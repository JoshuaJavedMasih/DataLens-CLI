# Contributing to DataLens CLI

Thank you for helping improve a Merhatta Softwares product.

1. Create a focused GitHub issue describing the dataset and expected behavior without sharing sensitive data.
2. Fork the repository and create a descriptive branch.
3. Keep runtime code compatible with Python 3.10+ and free of third-party dependencies.
4. Add tests for behavior changes and run `python -m unittest discover -s tests -v`.
5. Open a pull request explaining the change, edge cases, and verification.

Use small sample datasets that contain no confidential information. By contributing, you agree that your work may be distributed under the MIT License.
