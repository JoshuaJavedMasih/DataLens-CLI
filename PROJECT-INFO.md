## Product purpose

DataLens CLI provides a fast, private first look at unfamiliar tabular datasets. It reveals shape, inferred types, missingness, duplicate rows, common values, and descriptive statistics without uploading data or installing runtime dependencies.

## Current scope

Version 1.0 profiles delimited text files and produces portable reports. Automatic data correction, spreadsheet formulas, and machine-learning-based anomaly detection are outside the initial release.
