# Security policy

## Supported version

Merhatta Softwares currently supports the latest release on the `main` branch.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use the repository's **Security → Report a vulnerability** option to send a private GitHub Security Advisory. Include reproduction steps, affected files, likely impact, and any suggested remediation.

Merhatta Softwares will acknowledge a complete report as soon as practical and coordinate disclosure after a fix is available. Never attach confidential datasets to a report; use a minimal synthetic example.
